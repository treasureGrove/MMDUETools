使用教程

完整图文步骤在仓库里维护，含实际面板截图和每一步的按钮位置：

中文图文指南 English guide 日本語

1. 安装

解压发布包，把 Ue5MMDTools/ 放进工程的 Plugins/ 目录，启用插件并重启编辑器。也可以从编辑器控制台输入 MMD.OpenPanel。

YourProject/
  Plugins/
    Ue5MMDTools/

2. 导入角色并试动作

从 窗口 → Ue5MMDTools 打开角色工坊，点「导入 PMX 模型」，保留 PMX 与贴图的相对目录。导入一次后，之后点「加载已有角色」即可。选一个内置动作，再在面板底部开启 实时物理 检查发丝和衣物。

3. 换布光、定机位

切到 场景 选影棚，布景和配套光照一起切换；视口上方可选全身 / 半身 / 面部 / 侧面 / 背面。想试材质时切到 风格，随时可以恢复原材质。

4. 出片

确认动作、场景、风格和透视机位后，点右上角 按当前预览制作。成片在 Saved/MMDProduction/，需要 Windows D3D12 SM6，并能在 PATH 调用 ffmpeg 与 ffprobe。

插件功能说明

PMX 模型导入

  • 解析 PMX 顶点、索引、法线、UV、材质和骨骼。
  • 生成 UE SkeletalMesh 和 Skeleton。
  • 创建基础 MMD 材质和材质实例。
  • 保存 MMD ModelData 辅助数据。

MorphTarget / 表情

  • PMX vertex morph 导入为 UE MorphTarget。
  • 修正 PMX 顶点到 UE 渲染顶点的映射，避免表情扭曲。
  • VMD 表情写入 AnimSequence float curves。
  • 支持 Group / Flip Morph 展开，嘴型和眨眼可正常播放。

VMD 动作导入

  • 解析 VMD 骨骼关键帧和 Morph 关键帧。
  • 骨骼轨道写入 AnimSequence。
  • 表情轨道写入 Morph curves。
  • 支持 MMD 到 UE 坐标系转换和 IK / 追加骨骼烘焙。

Actor / AnimBlueprint / IK

  • 自动创建 MMD Actor。
  • 自动生成 AnimBlueprint。
  • 提供 MMD Skeletal Control 动画节点。
  • 生成 IK Rig 和 IK Retargeter。

物理模拟

  • 读取 PMX 刚体和 Joint 数据。
  • 基于 Bullet 初始化 MMD 风格物理模拟器。
  • 播放时实时模拟发丝与衣物；定格姿势后物理继续推进。
  • 出片时物理结果按帧推进，并可烘焙进 Sequencer。

影棚、布光与出片

  • 八套影棚预设，切换场景时布景与配套光照一起更换。
  • 风格预设可预览、可恢复原材质；视口提供五种机位。
  • 按当前预览后台渲染 30 fps MP4，输出帧序列与日志。
  • 命令行支持 import-pmx / import-vmd / render，结果以 JSON 返回。

当前限制

  • Material Morph 尚未完整驱动 UE 材质参数。
  • Bone Morph / UV Morph 还没有作为完整动画通道实现。
  • 不同模型的骨骼命名、IK 结构和特殊 Morph 组合可能需要继续适配。

工作流总结

Ue5MMDTools 会把 MMD 资源尽量转换为 UE 原生资产，并在同一个面板里完成布光、机位和出片。

PMX 模型
  -> SkeletalMesh
  -> Skeleton
  -> MorphTarget
  -> Materials
  -> MMD Actor

VMD 动作
  -> AnimSequence bone tracks
  -> AnimSequence morph curves

角色工坊
  -> 内置动作 / 自定义 VMD
  -> Bullet 物理（可定格继续模拟）
  -> 影棚与布光预设
  -> 全身 / 半身 / 面部 / 侧面 / 背面

出片
  -> 30 fps MP4（Saved/MMDProduction/）
  -> 帧序列与日志
  -> 可继续在 Sequencer 精修
