1. インストール

配布 ZIP を展開し、中の Ue5MMDTools/ をプロジェクトの Plugins/ に置いて、プラグインを有効化してエディタを再起動します。エディタのコンソールから MMD.OpenPanel でも開けます。

YourProject/
  Plugins/
    Ue5MMDTools/

2. キャラクターを読み込んでモーションを試す

ウィンドウ → Ue5MMDTools でスタジオを開き、导入 PMX 模型（Import PMX Model）で PMX を選びます。テクスチャは PMX と同じ階層に置いたままにしてください。2 回目以降は 加载已有角色（Load Existing Character）だけで読み込めます。内蔵モーションを選び、パネル下部の 实时物理（Real-time physics）をオンにすると髪と服の動きを確認できます。

3. 照明とカメラ

场景（Stage）でスタジオカードを選ぶと、セットと照明が一緒に切り替わります。ビューポート上部で全身／半身／顔／横／後ろを選べます。风格（Style）ではマテリアルを試せて、いつでも元に戻せます。

4. MP4 を書き出す

モーション、スタジオ、スタイル、パースカメラを確認して、右上の 按当前预览制作（Produce from current preview）を押します。出力は Saved/MMDProduction/。Windows の D3D12 SM6 と、PATH の通った ffmpeg / ffprobe が必要です。

できること

PMX の読み込み

  • 頂点、インデックス、法線、UV、マテリアル、ボーンを解析。
  • UE ネイティブの SkeletalMesh と Skeleton を生成。
  • MMD の基本マテリアルとマテリアルインスタンスを作成。
  • 再読み込みやツール用に PMX の情報を保持。

モーフと表情

  • PMX の頂点モーフを UE の MorphTarget に変換。
  • 頂点マッピングを補正し、表情の歪みを抑える。
  • VMD の表情をアニメーションの float カーブに。
  • グループ／フリップモーフを展開し、まばたきと口パクが動く。

VMD モーション

  • ボーンとモーフのキーフレームを解析。
  • ボーントラックを AnimSequence に書き込み。
  • 表情トラックをモーフカーブに。
  • MMD と UE の座標変換、IK／付与ボーンのベイクに対応。

Actor・アニメーションブループリント・IK

  • MMD Actor を自動で作成。
  • 読み込んだキャラクター用の AnimBlueprint を生成。
  • MMD スケルタルコントロールのアニメーションノードを同梱。
  • IK Rig と IK Retargeter を生成。

物理

  • PMX の剛体とジョイントを読み込む。
  • MMD 互換の Bullet ソルバで計算。
  • 再生中に髪と服をシミュレーション。ポーズを固定しても物理は継続。
  • 書き出し時はフレームごとに進め、Sequencer へベイクも可能。

スタジオ・照明・書き出し

  • 8 種類のスタジオプリセット。切り替えるとセットと照明が一緒に変わる。
  • スタイルプリセットは試着感覚で、元のマテリアルにすぐ戻せる。
  • 現在のプレビューを 30 fps の MP4 に。連番とログも出力。
  • コマンドライン：import-pmx / import-vmd / render、結果は JSON。

現在の制限

  • マテリアルモーフは UE のマテリアルパラメータを完全には駆動していません。
  • ボーン／UV モーフはアニメーションチャネルとして未実装。
  • 特殊な骨格、IK 構成、モーフの組み合わせはモデルごとの調整が必要です。
  • UI は既定で中国語。英語テキストは同梱済みで、日本語 UI はこれからの対応です。

パイプライン

MMD のデータは UE のネイティブアセットになり、照明・カメラ・書き出しまで同じパネルで完結します。

PMX モデル
  -> SkeletalMesh
  -> Skeleton
  -> MorphTarget
  -> Materials
  -> MMD Actor

VMD モーション
  -> AnimSequence ボーントラック
  -> AnimSequence モーフカーブ

MMD スタジオ
  -> 内蔵モーション / 手持ちの VMD
  -> Bullet 物理（ポーズ固定で継続）
  -> スタジオと照明のプリセット
  -> 全身 / 半身 / 顔 / 横 / 後ろ

書き出し
  -> 30 fps MP4（Saved/MMDProduction/）
  -> 連番とログ
  -> Sequencer でさらに編集
