### 1.5 Sky Light

**NOT packed into LightDataRT.** Sky ambient enters the shader via:
```hlsl
float3 SkyAmbient(float3 WorldNormal) {
    // SH evaluation: View.SkyIrradianceEnvironmentMap[0..6]
    return max(0, I0 + I1 + I2);
}
// Usage:
Final += BaseColor * SkyAmbient(Normal) * View.SkyLightColor.rgb;
```

This is identical to UE's PBR sky diffuse pipeline. The shader uses `View.SkyLightColor` as a multiplier, which includes the SkyLight actor's `Intensity` and `LightColor`.

## 2. Critical Observations

### 2.1 Unit Inconsistency (H001)

The same shader formula `Color.rgb × (C.w/π) × NdotL × Atten` is applied to all light types, but:
- **Directional:** C.w = lux (illumination on a surface, independent of distance)
- **Point/Spot/Rect:** C.w = candelas (luminous intensity, must be divided by distance² for illuminance)

The shader does NOT divide by distance² for point/spot/rect — it uses a simpler linear attenuation `1 - dist/radius`. This means:
- A point light at intensity 5.0 candelas at 200cm distance ≈ `5/π × NdotL × (1-200/600)` = ~1.06×NdotL
- A directional at intensity 5.5 lux ≈ `5.5/π × NdotL × 1` = ~1.75×NdotL

The directional appears brighter per unit intensity, which is actually physically correct (lux includes the solid angle contribution), but the user must know this when adjusting intensities.

### 2.2 DirLight Excludes Intensity (H002) — VERIFIED BY DESIGN

```hlsl
DirLight += C.rgb * NdotL * Atten;   // No C.w
```

This means the Toon Ramp position is determined solely by light direction and color balance, NOT by intensity. A 100% white light and a 10% white light produce the same ramp position.

**Implication:** A weak auxiliary light contributes the same ramp influence as the main light if they have the same color. This is the core of H002's concern.

### 2.3 Face Main-Light Selection (H003)

```hlsl
float Weight = C.w;  // Intensity as weight
if (Weight > BestWeight) {
    BestWeight = Weight;
    MainLightDirWS = normalize(-D.xyz + 1e-5);
}
```

- No distance consideration for point/spot lights
- Ties broken by slot order (closer distance → lower slot index for same intensity)
- **Risk:** Two lights at similar intensities can flip the main light direction between frames if their relative brightness fluctuates
