## MCP Automation Breakthrough

`set_properties` 的 `values` 参数必须传 JSON 字符串（`json.dumps()`），不能传 dict。

示例：
```python
mcp_call("call_tool", {
    "toolset_name": "editor_toolset.toolsets.object.ObjectTools",
    "tool_name": "set_properties",
    "arguments": {
        "instance": {"refPath": "...LightComponent0"},
        "values": json.dumps({"Intensity": 1.0, "Temperature": 6500.0})
    }
})
```

已验证可修改的属性：
- Intensity (float)
- Temperature (float)
- UseTemperature (bool)
- LightColor (FLinearColor: {r, g, b, a} 0-1 range)
- AttenuationRadius (float, PointLight)
