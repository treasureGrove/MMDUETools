# 10 周年初音的两组影棚镜头

2026-11-05（Asia/Singapore）使用 UE 5.8.3／CL58210709、D3D12 SM6 与原生 Mode 2 离屏渲染。两张图均为原样归档的第 18 帧（从 0 开始），1024×768。

- **纯白影棚 · 胸像**　使用默认纯白影棚与偏右透视机位。原片 21 帧，记录 100 次 Bullet 步进（含预热）。[原图](studio_portrait.png)
- **深蓝展厅 · 侧脸**　使用深蓝展厅与偏左透视机位。原片 27 帧，记录 112 次 Bullet 步进（含预热）。[原图](slate_portrait.png)

两组沿用侧脸待机的模型、动作和表情轨道，关闭捕获投影。它们用于比较不同镜头与布光的构图效果。原始成片和渲染报告存于本地 `Saved/YYBShowcase/2026-11-05/10th-refine/homepage-gallery/`。[薰紫摄影棚待机与捕获记录](../2026-11-05-nikki-face-fill/README.md)
