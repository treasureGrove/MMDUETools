# MMD 工具面板

更新于 2026-11-04。从编辑器的 **窗口 → Ue5MMDTools** 打开 **MMD STUDIO / 角色工坊**。面板采用冷白、淡蓝紫、深蓝文字、细线卡片和原创菱形星标，预览区的灯光由所选场景提供。

[生成式界面概念及完整提示词](Design/2026-10-23-anime-ui/README.md)只用于设计参考。实际面板使用原生 Slate 控件，标题、按钮、选中态和星标随 DPI 缩放；右侧持续显示实际加载的角色和环境，不用概念图中的角色或缩略图代替渲染结果。

## 动效与反馈

[2026-10-25 实际面板截图、时间戳动效视频与测试记录](Screenshots/2026-10-25-ui-experience/README.md)保留 run8 的历史交互版本；其中云空默认场景已被用户否决，不能作为当前默认效果。可选外部环境的来源与接入边界见[Fab 环境候选](FAB_ENVIRONMENT_OPTIONS.md)。

面板按钮支持120–160ms的悬停上浮、按压回弹与键盘焦点反馈；角色／风格／场景页使用180ms指示条滑动和轻微淡入。实际页面立即可操作，快速连续切换从当前指示条位置衔接。右上角「界面动效」可即时关闭这些过渡，偏好保存在本机工程用户设置中；角色动画与实时物理独立运行。动效结束后停止活动计时器，指示条不运行空 Tick。

底部状态栏固定为单行，使用「提示／完成／注意／失败」区分操作结果；长消息以省略号显示，悬停查看全文，也可点「复制」复制完整内容。结果持续保留，不因淡入效果而自动消失。

风格页支持按中文名称、效果描述、英文名称搜索，多关键词用空格分隔；计数与无结果提示即时更新。命中兼容方案会自动展开，清空搜索恢复之前的展开状态。同一目标重复选择当前风格会保留现有材质实例；修改配方后需要刷新，可按住 Shift 点击卡片按钮。「恢复原材质」位于目标区，方便随时返回。

## 角色与动作

按「选择角色 → 姿势与动作 → 制作与输出」操作。可导入 PMX，或从内容浏览器加载已有 MMD 角色。标准 MMD 骨架加载后默认播放 **恬静待机**；四个预设为恬静待机、轻柔呼吸、侧头思考、整理衣摆，分别保留作者4／2.5／约2.833／2秒时长，直接点击即可替换右侧循环预览，头发、衣物继续实时计算物理。

当前使用 **MMDAgent 的 Mei 女性角色配布动作**，来自 [MMDAgent Sample Script 1.8 官方包](https://sourceforge.net/projects/mmdagent/files/MMDAgent_Example/MMDAgent_Example-1.8/)，原始 VMD 未改写，保留完整肩／肘／腕／手指轨道。按作者 CC BY 3.0 分发，面板和资源目录均保留署名；详见[动作来源和许可](../Resources/PreviewMotions/README.md)。前轮程序生成的四组动作已被用户否决，现已从面板与分发资源撤下，不能引用其测试通过来宣称动作观感合格。

预设复用正式 VMD 导入器及 ModelData 骨骼映射，在内存中按当前骨架生成动画并缓存；换角色清空缓存。顶部「按当前预览制作」可直接使用这些内置动作。要在合成器或物理烘焙面板里选取预设动作，可从插件 `Resources/PreviewMotions/MMDAgent` 导入对应 VMD，生成正式资产。不同模型的肩宽、臂长和手指比例会影响接触姿势，整理衣摆等动作适合先在预览中检查。

播放、进度、倍速、定格与实时物理集中在**预览区底部固定栏**，切换角色／风格／场景页都可使用，不随左侧内容滚走。动作卡片显示动作说明、时长和「当前」标记；重复点击当前卡片不重播，不同动作之间保留暂停、倍速、定格及物理开关。新载入角色保留倍速／物理选择，清除旧定格和拖动状态，默认进入待机。

「暂停／继续」同时控制动作时间和 Bullet 运算，暂停保留最后物理姿态。「定格姿势」只锁住动作时间，播放状态下头发／衣物继续实时运算；再次点击「解除定格」恢复动作。定格时切换其他动作保留相对时间位置，也可拖动进度挑姿势。倍速提供0.5×／1×／1.5×，仅控制动作推进速度，定格时保留所选速度供解除后使用。

「重播」退出定格、回到0秒、重建物理并继续正常播放。拖动进度临时暂停，放开恢复此前播放状态，原先暂停则仍暂停；鼠标及手柄捕获使用同一规则。时间跳转会重置旧物理状态，片尾正常循环则保持物理世界连续。「重置物理」保留当前动作时间和机位；「编辑 → 恢复原始姿态」清空动作并停止物理，重新点动作卡片可恢复。

时间轴两端的「‹ 帧／帧 ›」按当前动画实际采样帧率定位相邻帧，暂停动作与物理以便检查姿势，首尾不会绕回。时间显示精确到0.01秒。键盘聚焦时间轴后按 Enter 开始微调，方向键每次移动一个采样间隔，再按 Enter 结束并恢复此前播放状态。

「实时物理」默认开启，使用当前模型的 MMD 刚体和关节，状态显示实际初始化结果、运行／暂停和刚体数。无动作／无刚体时相关控制置灰并提示；非标准骨架映射不足时保留原动作并提示，不能承诺任意非 MMD 骨架都能直接套用。旧资产若没保存物理数据且原 PMX 也已丢失，需要重新导入源模型才能恢复物理配置。

自己的 VMD 动作、追加表情和相机放在折叠区「导入自己的 VMD／表情／相机」。导入相机会填入合成器的相机槽。物理烘焙完成后，烘焙结果会填入合成器的动画槽，烘焙区仍保留原输入。切换角色时，面板会清理与新角色骨架不兼容的动画选择。

要把当前展示直接做成 MP4，保存角色和自定义动画，选好风格、场景与透视机位，再点顶部「按当前预览制作」。后台从动作开头制作，沿用预览倍速和物理开关。面板显示进度、输出位置与取消按钮。[后台制作工作流](MMD_PRODUCTION_WORKFLOW.md)

MMD Standard 导入选项和旧 Aurora Jewel 资产操作收进「高级选项与旧版工具」。Aurora Jewel 的按钮明确标注会保存角色蓝图，撤回入口与其放在一起。

## 风格预设

先选择作用范围，再点「预览风格 →／预览到关卡所选 →」；实际应用后按钮显示「已应用」：

- **预览角色**：只替换右侧预览角色的材质。
- **关卡所选**：仅处理当前编辑关卡中选中角色的骨骼网格，支持多选；运行游戏时不可应用。

页签用蓝紫下划线显示当前页面，作用范围用蓝紫实心按钮显示；已应用的风格卡片有淡紫底、蓝紫描边和勾选文字。角色卡片中的 V2／N 是方案标识，不是虚构的效果缩略图。

主区提供 **终末地 V2** 与 **无限暖暖**。完整原生效果沿用已有 Substrate、原生后端与 Profile 条件，面板显示当前是否就绪，不代改工程配置。[架构与回退说明](RENDERING_ARCHITECTURE.md)。

「更多风格 · 兼容预设」包含明快卡通、银白柔光、电影冷暖、工业动画、霓虹演唱会、月光镜庭、樱庭水镜和旧终末地。自定义资产选择器接受 `MMDStageRenderPreset`，选取后立即应用到当前作用范围。

调用现有 `MMDStageLibrary`，保留源贴图、底色、部位分类和原生父材质选择规则。「恢复原材质」恢复首次套用前的材质覆盖、描边与相关阴影设置。连续切换方案不会把上一个方案当作原始材质。

**这些角色切换是本次会话中的临时实例效果**，不写角色蓝图、网格或材质资产。保存关卡前暂时恢复原材质覆盖，保存完成后重新显示预览，避免将临时 MID 写入关卡；关闭面板时恢复本面板应用的关卡角色材质。重新加载角色／关卡后需要再次应用。现有临时恢复状态不提供跨会话恢复，也不以 Ctrl+Z 代替「恢复原材质」。

## 预设场景

默认预览恢复为**纯白影棚（`Studio`）**，沿用原有浅色渐层、哑光地面与简洁圆台。主区提供纯白影棚与四套新增影棚，一键切换布景和配套光照，保留角色材质、动作、播放位置、定格、倍速与物理选择：

| 展示 | 布景 | 光照 |
|---|---|---|
| 纯白影棚（`Studio`，默认） | 原版浅色渐层、简洁哑光圆台 | 校准三点光 |
| 樱雾柔光（`RoseStudio`） | 柔粉无缝背景、圆润细边台 | 接近中性的柔和人像光 |
| 深蓝展厅（`SlateGallery`） | 低饱和深蓝、哑光展台、两侧柔光板 | 中性面光、清冷轮廓光 |
| 珍珠回廊（`PearlAtrium`） | 珍珠白空间、偏侧弧墙、细腻竖槽 | 暖白主光、柔和漫射补光 |
| 薰紫摄影棚（`LilacStudio`） | 浅紫渐层、简洁宽背板、低矮侧台 | 柔亮面光、淡紫轮廓光 |

此前的晴空露台（`SkyGlass`）、暮色星台（`VioletStage`）、暖光画廊（`WarmAtelier`）保留在默认收起的「早期云空场景」中，只有主动展开后才显示卡片。该云空版本已被用户否决，不再作为默认展示或当前观感依据。

八套展示均固定 EV0，避免构图或深浅背景改变角色测光。纯白影棚和新增四套影棚使用引擎中的布景与材质；早期三套云空使用既有生成式天空艺术图片，其来源、原图与限制仍见[展示天空资源说明](../Resources/DisplayScenes/README.md)。天空图片不作为 HDRI 光照源，近处地面与角色接受对应方向光和天光配方的真实光照。布景为临时内存组件，切换不会保存或覆盖资源。电影入口也支持对应 `Stage` 标识，见[后台制作工作流](MMD_PRODUCTION_WORKFLOW.md)。

新展示未保存为独立关卡，对应打开关卡入口会禁用；影棚入口明确为「光照参考关卡」，不把瞬态展示几何当作已保存地图。场景页底部「浏览 Fab 场景素材」打开官方 UE 页面，加入库后通过 UE「窗口 → Fab」添加到项目；本轮没有自动领取或导入 Fab 包。[候选与接入说明](FAB_ENVIRONMENT_OPTIONS.md)。

霓虹演唱会、月光镜庭、樱庭水镜分别提供：

- **预览舞台**：在隔离的预览世界中加载实际 `MMDStageActor`，沿用舞台 DataAsset 的灯光与后处理，隐藏中性检查台并移除检查台灯光。预览固定在初始时刻，方便对照材质；不修改关卡。换角色后继续使用所选环境。
- **放入关卡**：在当前可编辑层级的原点生成舞台，并同步右侧预览。保存关卡即可保留。后续切换复用该层级内带 `MMDToolPanelStage` 标签的舞台，保留其位置、旋转和缩放。锁定层级不操作，用户原有无此标签的舞台不参与自动替换。

角色风格与舞台场景分别选择，换舞台不会自动改角色材质。

光照区提供八套既有布光：三点布光、户外日光、阴天柔光、室内暖光、赛博霓虹、轮廓剪影、黄金时刻、恐怖绿光。点击名称移除预览舞台并保留角色风格；三点布光使用纯白影棚，其余七套保留对应 LookDev 参照。检查台内切换布光保留镜头，舞台与检查台切换则使用对应机位。当前环境以蓝紫实心按钮和视口顶端 LookDev 状态显示，预览中的舞台卡片也会高亮。风格切换不会暗中替换所选环境。

统一的「打开当前预览对应关卡…」入口按当前舞台／布光打开完整关卡；先走 UE 未保存关卡提示，取消后保持当前关卡。缺失的标准布光关卡沿用已有库的生成行为。

## LookDev 对应关系

既有标准布光中的 HDRI 背景读取对应环境配方的 Cubemap、旋转和强度。黄金时刻使用日落 HDRI 与 25° 天光旋转，不再沿用日间背景或固定 1000 倍背景强度。没有天光的霓虹／剪影／绿光环境不额外补一盏默认天光。早期三套云空场景使用独立的天空艺术图片，其角色光照由配套方向光与天光配方提供，不能把图片明暗等同于 HDRI 辐照度。

舞台预览使用真实舞台的灯光与后处理，兼容材质从实际预览世界生成灯光覆盖；原生材质继续使用 UE 当前场景光源。主光拥有更高的前向光照优先级，避免透明等单主光路径与辅光争用。

默认纯白影棚保留原有三点布光，主光／辅光／轮廓光为3.2／0.55／1.25，天光0.45。新增四套影棚各有配套的方向光与天光配方，切换布景时一并切换。原生与兼容路径读取当前灯组的同一组方向、颜色和艺术强度；只有主光投影并拥有较高的前向优先级。八套角色展示均固定手动曝光 EV0，关闭物理相机曝光和曝光偏移曲线，不再因模型占比或黑衣比例重新测光。暖暖皮肤的暖色、饱和度与表面粗糙度校准发生于 2026-10-23；本轮沿用该配方，没有重新生成这些材质资产，也没有改共享 v15 原生入口。

默认预览和后台未指定 `Stage` 时都恢复为纯白影棚（`Studio`），保留原有浅色渐层背景、哑光地面和细边圆形展示盘，不将云空纹理套入默认环境。远地面渐变融入对应背景，近地面和展示盘保持真实受光与投影。展示几何与材质只驻内存，不写角色或材质资产；其他七套 LookDev 环境仍保留各自背景与参照。

当前宿主将 `r.Shadow.Virtual.Enable` 设为0，使用常规阴影／CSM。2026-10-23 的 YYB16th 模型测试中，VSM 自阴影出现三角块，CSM 对照保留正常投影且未出现该块状伪影；本轮沿用当时的回退，没有重测 VSM。这是该模型与配置的历史实测回退，不代表所有 UE／VSM 都有相同问题。后台制作也可显式选择 `-ConventionalShadows`。

其余七套检查环境继续使用工程曝光；切换时移除展示场景的手动曝光覆盖。舞台始终使用自身后处理。视口状态显示实际采用「固定曝光／自动曝光／舞台原配后处理」，不会同时叠加两套设置。预览场景每帧更新天空与反射捕获，并允许 Lumen 追踪预览物体；这不替代工程自身的 GI／反射配置，也不代表已完成完整画质或性能验收。

插件自带的 `LE_Studio3Point` 使用纯白影棚的灯光与曝光配方，2026-10-23已定向重建；日志见 `Saved/MMDProduction/2026-10-23-studio-map/engine.log`。浅色展示几何由面板／后台 helper 创建，不能把灯光关卡同步等同于保存了全部瞬态展示场景。维护命令 `MMD.RebuildLookDev Studio3Point` 只重建并保存指定环境；无参数仍会重建全部八套关卡。命令用于维护插件自有资源，不在面板日常操作中自动执行，也不自动覆盖用户已修改的关卡。

检查台镜头为 35°，视角复位依据模型包围盒、视口比例和 FOV 计算距离。舞台采用现有场景生成器的默认机位：樱庭 50°、其余 55°，避开舞台前景遮挡；模型自身朝向由用户通过旋转工具调整。预览隐藏编辑器橙色选区边及灯光图标，PMX／材质描边保持原样；移动、旋转、缩放及隐藏手柄收在「编辑」菜单，保留 W／E／R；按住右键时 W／E／R 交给镜头导航。

视口上方新增「全身／半身／面部／侧面／背面」角色机位，按模型尺寸和当前视口比例取景，面部优先使用头骨位置。切换在0.3秒内平滑移动，右键／中键／滚轮／Alt+左键手动导航时接管；过渡途中按空格暂停或 Home 重播仍会完成取景；不会转动模型、切换 LookDev 或暂停物理。「场景机位」恢复当前舞台／检查台原有构图。更换骨架或调整模型姿态后可重新点机位按钮取景。调整窗口或左右分栏大小后，仍选中的角色机位和当前展示场景机位会按新画幅重新取景；已手动导航的机位保持用户的位置。舞台自身的固定主镜头仍保留配套构图。

预设机位高亮显示，进入右键／中键／滚轮等手动导航后清除预设选中态。**仅视口获得焦点时**响应空格暂停／继续、Home重播、1—5对应五种角色机位、F全身取景；有 Ctrl／Alt／Shift／Command 修饰或右键导航时不拦截这些快捷键，不注册编辑器全局按键。空预览中央提示从左侧加载角色，相关播放控件保持禁用。

## 验证入口
