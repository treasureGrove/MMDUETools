本仓库是 Unreal Engine 5 的 MMD 导入与播放插件，核心代码为 C++/Blueprint 资产，不包含任何前端 UI 或游戏内界面样式。唯一的前端相关资源是 `docs/index.html`——一个用于 GitHub Pages 发布的单页说明文档，其样式全部以内联 `<style>` 块形式写在 HTML 头部，未使用 CSS 文件、SCSS、Tailwind 或其他样式框架。

该页面采用现代 CSS 变量（`:root` 中定义 `--bg`、`--panel`、`--text`、`--accent` 等）作为轻量设计令牌，配合原生 Flexbox/Grid 布局实现响应式排版；配色以浅色为主（`color-scheme: light`），强调色为蓝色系，整体风格简洁、偏技术文档风。没有组件库、主题切换或构建管线。

结论：此仓库不存在“前端样式系统”这一跨切面关注点，仅有一个内联样式的静态文档页面。
